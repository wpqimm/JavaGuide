# ProjectLearn (JavaGuide)

Декстопное приложение-гид для изучения Java от теории до практики

## 🚀 Функционал

* Авторизация и регистрация пользователей
* Просмотр теоретического материала (загрузка изи .txt файлов)
* Тестирование знаний (проверка по ключевым словам)
* Практические задания с проверкой кода (находится в доработке)
* Просмотр статистики (личная и общая) с использованием SQL-запросов (JOIN, GROUP BY)
* Мини игра "Секрет"

## 🛠 Технологии

* **Язык:** Java 17+
* **UI:** Swing 
* **База данных:** SQLite (JDBC, PreparedStatement)
* **Сборка:** Maven
* **Контроль версий:** Git

## ⚙️ Как запустить

1. Клонируйте репозиторий: `git clone https://github.com/ваш_ник/ProjectLearn.git`
2. Откройте проект в IntelliJ IDEA.
3. Запустите класс `Main`.
