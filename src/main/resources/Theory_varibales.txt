Переменная - это имя, которое ты даешь значению, а тип говорит, что можно хранить.

Основные типы данных:

1. int - целые числа (int age = 25;)

2. double - числа с точкой (double price = 2.55;)

3. boolean - правда/ложь (boolean isStudent = true;)

4. char - один символ (char grade = 'A';)

5. String - текст (String name = "Друг";)

String - это не примитив, а разновидность класса, но он ведёт себя почти как тип.

Как объявить переменную:

int age = 25;

Для тебя покажется, что это просто команда, но на самом деле нет.

int - говорит нам (введи целое число, не текст, не дробное. Только целое)

age - переменная (в нашем случае это возраст)

25 - значение (целое число)

Таким образом мы объявили переменную age = 25.

Зачем нужны разные типы?

Если использовать разные типы, то компьютер поймет: сколько памяти ему выделить и какие операции он сможет сделать.
Числа можно складывать, текст склеивать.
