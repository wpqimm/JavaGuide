Что такое операторы?

Операторы - это знаки, которые говорят, что делать компьютеру. Как дорожные знаки для водителя.

Арифметические операторы:

 + (сложение), - (вычитание), * (умножение), / (деление), % (остаток от деления).

1. Сложение - int a = 10 + 5; (a = 15)

2. вычитание - int b = 10 - 5; (b = 5)

3. умножение - int c = 10 * 5; (c = 50)

4. деление - int d = 10 / 5; (d = 2)

5. остаток - int a = 7 % 3; (остаток равен 1)

Операторы сравнения:

 > (больше), < (меньше), >= (больше или равно), <= (меньше или равно), == (равно), != (не равно)

 Результат сравнения - всегда boolean (true/false)

Например: int age = 20; boolean isAdult = age >= 18; (true)

Логические операторы:

 && (И), || (ИЛИ), ! (НЕ).

Например: boolean canVote = age >= 18 && isCitizen; (можно голосовать если больше или равно 18 и есть гражданство).

Что такое isCitizen? Это переменная  типа boolean, которая показывает есть ли у человека гражданство.

boolean isNotAdult = !isAdult; (будет false, если isAdult - true)
